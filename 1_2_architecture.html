DBMS Architecture

This page is a saved note on DBMS architecture. It covers the three-schema architecture (internal, conceptual, external), components of a DBMS, and client-server vs centralized designs.

Three-schema architecture

  • Internal schema: Physical storage structure
  • Conceptual schema: Logical structure of the entire database
  • External schema: Views for specific users

DBMS components

Storage manager, query processor, transaction manager, recovery manager, and authorization & security modules.
